## سؤال‌های باز (پاسخ می‌خواهند)
1. عدد رسمی حداقل محصول چیست و برای کدام Categoryها پایین‌تر است؟
2. نمایش اینماد روی سایت و Agreement دقیقاً چه چیزی را چک می‌کنند و Reason NBO‌شان چیست؟
3. Timeout سایت = Manual یا EDIT؟
4. فایل/Excel واقعی موتور Duplicate-Cancel کدام است (reject_engine.xlsx؟).
5. Marker داخلی Online Insta چه کلمه‌ای است؟
6. لیست دقیق Reasonهای NBO (عین متن).
